# 步骤 06 · 前端壳、快捷键体系与基础体验

> 目标：搭建产品级「壳」——未登录只能看到登录/注册页；登录后是侧边栏应用壳；双主题（Midnight 默认 / Daylight 纸白）；全局快捷键体系；命令面板；Toast 与撤销；空态与骨架屏。本步骤不实现业务页面内部，只交付框架与全局交互。

## 6.4 登录/注册页规格（白泽观智风）

```
布局：左 55% 品牌区 / 右 45% 表单卡（<900px 堆叠为单列，品牌区压缩为顶栏）
品牌区：
  - 背景 #F7F3EC + 40px 淡网格（rgba(15,23,42,.045)）（Daylight 恒定，不随主题切换——
    登录页是产品的「印刷品」，保持纸白以传递专业与信任）
  - 衬线大标题「VibeHub」+ 金色圆点；副标语：人类粘贴，AI 消费。
  - 三个特性 Bento 卡（截图即录 / AI 直读 / 双向同步），各配 1.8 描边线性图标
  - 终端风代码块：~/.cursor/mcp.json 示例 + 一键复制（教育前置）
  - 金色光标聚光（克制版：560px 径向，opacity .5，仅桌面端）
表单卡（玻璃 2.0：rgba(255,255,255,.92) + blur(20px) + 1px 高光边）：
  - Tab：登录 | 注册（滑块指示器 220ms）
  - 登录：邮箱 / 密码（显示切换）/ 记住我 / [登录] / 第三方 GitHub·Google / 忘记密码（mailto 说明）
  - 注册：名字 / 邮箱 / 密码（强度条：弱中强三色）/ [创建账号]
  - 错误：红字 + 抖动一次（160ms）；成功即登录进主界面（无二次跳转）
  - 底部：协议行（勾选才可提交）+ 「© 2026 VibeHub」
```

交互细节：Enter 在任一输入框即提交；提交中按钮金色流光扫过；`REGISTRATION_OPEN=false` 时隐藏注册 Tab 并显示「请联系管理员创建账号」。

## 6.5 快捷键体系（全产品宪法）

| 键 | 作用域 | 行为 |
| --- | --- | --- |
| `C` | 全局（非输入态） | 打开新建缺陷 |
| `⌘/Ctrl+K` | 全局 | 命令面板 |
| `?` | 全局（非输入态） | 快捷键帮助 |
| `Esc` | 全局 | 关浮层 → 清选择 → 清搜索（逐层） |
| `G B/F/T/P/K/M/,` | 全局 | 连按导航（G 松开 800ms 内有效） |
| `⌘/Ctrl+Enter` | 表单 | 提交 |
| `J/K` `↑/↓` | 列表 | 移动焦点项 |
| `Enter` | 列表 | 打开焦点项 |
| `X` | 列表 | 切换多选焦点项 |
| `⌘/Ctrl+A` | 列表 | 全选当前筛选 |
| `/` | 列表 | 聚焦搜索框 |
| `T` | 看板 | 切换主题（ hidden gem） |

`shortcuts.ts` 契约：注册表集中定义（含 description，供 `?` 面板自动渲染），输入态（input/textarea/contentEditable）自动放行，`⌘` 系列始终捕获。

## 6.6 Toast 与撤销

```ts
toast.success('已删除 3 个缺陷', {
  action: { label: '撤销', onClick: () => restore(ids) },   // 5 秒倒计时进度条
  duration: 5000,
});
```

规则：所有删除/批量操作**不弹 confirm**，走撤销 Toast；仅「删除项目」「移除成员」「转让 Owner」用 ConfirmDialog（输入名称确认）。

## 6.7 验收标准

- [ ] 未登录访问任何 `(app)` 路由重定向 `/login`；登录后回跳原路径

- [ ] 删除走 Toast 撤销且 5 秒后 action 消失；删项目弹名称确认
- [ ] 登录页在 900px 以下正确堆叠；表单卡玻璃效果在 Daylight 下不透明到底（对比度 AA）
