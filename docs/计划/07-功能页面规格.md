## 7.1 看板页 `/board`

### 布局

```
┌─ 顶栏 ───────────────────────────────────────────────┐
│ [项目切换器 ▾]  活跃 N · 已选 M(出现时)  [筛选 ▾] [视图 ▾]  ⌘K ☾ +新建 C │
├──────────────────────────────────────────────────────┤
│ 筛选条（可折叠）：[状态][严重度][指派][标签][截止][搜索 /]  [清除]  [保存视图] │
├──────────────┬──────────────┬──────────────┬─────────┤
│ Open    抓卡 │ In Progress  │ Resolved     │ …横向滚动…│
│ ┌──────────┐ │ ┌──────────┐ │ ┌──────────┐ │         │
│ │卡片       │ │ │卡片       │ │ │卡片       │ │         │
│ │标题(内联改)│ │ │标题       │ │ │标题       │ │         │
│ │[ Sev 指派]│ │ │[ Sev 指派]│ │ │✓ AI修复说明│ │         │
│ │📎2 ↻1     │ │ │📎0       │ │ │commit hash │ │         │

```

### 卡片规格

- 结构：标题（两行截断，点击进入编辑态）/ 元数据行 / 缩略图条（最多 3 张，超出 `+N`）/ 标签行 / 底部行。
- 元数据行：严重度色点（critical 红 / high 橙 / normal 蓝 / low 灰）+ 指派头像（未指派显示 `+` 虚线圆，点击直接派给自己）+ 截止日（逾期红字）+ 📎附件数 + ↻重开数（>0 才显示）。
- AI 痕迹：`created_by=ai` 或最后Comment作者为 ai → 卡片右上金色星尘点 + 顶部 1px 金色流光（SSE 到达时播放一次，400ms）。
- 右键菜单：复制单 / 改状态子菜单 / 指派子菜单 / 加标签 / 删除（带撤销提示）。⌘点击=多选，Shift 点击=范围选。

### 拖拽

- HTML5 DnD；拖起缩放 1.02 + shadow-2；目标列高亮（金色 18% 边框）；落到非法状态列时列头抖动拒绝（如 Viewer 不可拖——viewer 无拖拽权限，卡片不 draggable）。
- 拖拽中 ⌘ 松开 = 复制到该状态？——**不做**（复制会产生歧义），保持单一语义。

### 新建缺陷对话框（`C`）

```
┌ 快速录入 ─────────────────── [模板 ▾] ┐
│ [粘贴区：Ctrl+V 或点击选择]            │   ← 上传中显示金色流光进度条
│  [缩略图][缩略图] +N                    │
│ 标题 ________________________ （autofocus）│
│ 复现步骤 ______________________ ⌘↵ 发送 │
│ 严重度  ○低 ●中 ○高 ○紧急   指派 [我▾]   │
│ 标签 [ui ×][p0 ×] [+ 添加]    截止 [日期] │
│ [取消]                    [创建  ⌘↵]     │
└──────────────────────────────────────────┘
```

- 模板菜单选择后自动填充标题骨架与默认字段（如「线上事故」预置时间线步骤）。
- 粘贴区支持多图与文件混合；每个缩略图可移除；上传失败单文件红框 + 重试。
- 创建成功：Toast「已创建 bug_xxx」+ 看板新卡片金色高亮闪入 + 对话框保持打开（连续录入，Esc 关闭）——**测试连录十个缺陷不打断**。

### 视图（Excel 式）

- 「视图 ▾」：我的待办 / 我创建的 / 全部 / 最近 7 天更新 / + 保存当前视图。保存时弹轻量命名；`is_default` 进设置。

## 7.2 文件页 `/files`

```
┌─ 顶栏：[我的 | 全部]  用量 3.2GB/10GB(进度条)  [类型▾][搜索 /][上传] ─┐
├──────────────────────────────────────────────────────────────────┤
│ 网格视图(默认) / 列表视图切换                                         │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐                                        │
│ │缩略图│ │缩略图│ │📄   │ │🎞   │   文件卡：悬停浮层 [查看][下载][删除] │
│ │名称  │ │名称  │ │名称  │ │名称  │   底部：大小 · 上传者头像 · 时间      │
│ └────┘ └────┘ └────┘ └────┘   多选：⌘点击 / 框选                       │
├──────────────────────────────────────────────────────────────────┤
│ 回收站（折叠区，Admin 可见全部人的删除；30 天倒计时；可恢复/彻底删）      │
└──────────────────────────────────────────────────────────────────┘
```

- 上传：点击 / 拖拽入页面任意处 / 全局粘贴（归属轻菜单：项目 + 可选关联缺陷）。上传并发 3，失败重试。
- 图片灯箱：←→ 切换、滚轮缩放、`i` 显示信息（尺寸/大小/上传者/MCP 来源）、Esc 关。
- 文本文件：点击进 TextViewer（既有，加分页+grep 高亮+行号跳转输入框）。
- 删除：自己的文件直接删（撤销 Toast 5 秒）；他人文件仅 Admin+。
- AI 上传的文件：金色「AI」徽章 + tooltip「由 MCP 密钥 cursor-main 上传」。
- 空状态：「还没有文件。按 C 录缺陷时粘贴截图，或把文件拖到这里。」

## 7.3 任务页 `/tasks`

- 三列（Todo/Doing/Done）看板或列表双视图（与缺陷看板共用组件，配置驱动）。
- 任务卡片：标题、优先级色点、关联缺陷徽章（`#3`）、指派人。
- 批量改状态/优先级；任务可一键转缺陷（保留内容为复现步骤）。

## 7.4 项目页 `/projects`

- 表格：名称 / slug（等宽字体 + 复制按钮，tooltip「AI 靠它匹配你的仓库」）/ 缺陷统计（活跃 N · 已解决 M · 文件 K）/ 创建人 / 更新时间 / 操作（进入·归档·删除）。
- 新建/编辑弹层：名称 + slug 自动生成（可改，唯一性校验）+ 描述。
- 归档项目沉底灰色区，可恢复；删除需输入项目名确认，确认文案列出将删除的缺陷/文件数并说明「文件进回收站保留 30 天」。

## 7.5 密钥页 `/keys`（Admin+）

```
┌─ 密钥 ────────────────────── [+ 创建密钥] ┐
│ Bento 概览：本月调用 12,480｜活跃 3｜峰值 QPM 240｜失败率 0.4% │
├────────────────────────────────────────────┤
│ 表格列：名称 | 前缀 | Scope 药丸 | 绑定项目 | QPM 配额条 | 最后使用 | 状态 │
│ 行操作：轮换 · 撤销（撤销弹原因输入）· 查看用量                    │
├────────────────────────────────────────────┤
│ 用量图（近 30 天堆叠柱：按工具）+  Top 工具表 + 最近调用审计表         │
└────────────────────────────────────────────┘
```

- 创建向导 3 步：①名称+绑定项目 ②Scope（默认仅 context:read，写操作显式勾选，每项旁注将开放的工具清单）③过期（默认 90 天，可选永久/自定义）。
- 第 3 步展示一次性明文：等宽大字 + 金色描边卡 + 「复制」+ MCP 配置 JSON 一键复制 + 红色警告「关闭后不可再查看」。
- 配额条：>80% 琥珀 >95% 红；`最后使用` 超 7 天置灰提示「闲置密钥建议撤销」。
- MCP 密钥被撤销时 Web 端 Toast 提示？（反向链路：见 7.1 AI 流光说明，保持简单——撤销即时生效即可）。

## 7.6 成员页 `/members`（Admin+）

- 表格：头像+名字 / 邮箱 / 角色（下拉即改）/ 状态徽章 / 最近登录 / 统计（建单数·上传数·MCP 调用）/ 操作（禁用·移除）。
- 顶部：注册开关（Owner 可见，Switch + 说明文案）、邀请区（复制注册链接 / REGISTRATION_OPEN=false 时显示「建号」按钮）。
- 行规则：最后一个 Owner 的角色/禁用/移除按钮禁用 + tooltip「系统需要至少一名 Owner」；不能改自己角色；移除成员弹确认（说明其数据保留）。
- Owner 专属区底部：「转让 Owner」危险区（输入对方邮箱确认）。

## 7.7 设置页 `/settings`

- 个人：名字、头像色（从 8 色板选，非图片上传——单机版从简）、改密（旧密码+新密码+强度条）。
- 偏好：默认主题、默认项目、看板默认视图（联动 SavedView.is_default）、密度（紧凑/舒适）。
- 系统（Owner）：注册开关、附件保留期、修改后即时生效 + 审计留痕。

## 7.11 随手记页 `/notes`（R50 实现；补 R17 IA 缺口）

- 布局：瀑布流（CSS columns，1/2/3 列响应式），便签卡 break-inside-avoid
- 便签卡：实时 Markdown 渲染（react-markdown + remark-gfm）；置顶卡金色描边 + 「置顶」标记；标签 chips 点击即筛选；底栏相对时间 + 附件数 + 「已编辑」标记
- 置顶（R50）：`pinned` 开关经 PATCH /api/notes/:id；列表排序 `pinned_at desc nulls last, created_at desc`
- 交互：`N` 新建 / ⌘↵ 发送 / `G N` 导航；底部标签过滤栏（含计数）
- 空态四要素：图标 + 人话 + 快捷键提示 + AI 写入说明

## 7.12 首启向导（R56 实现）

- 触发：登录后 localStorage `vibehub_onboarded` 缺失 → 自动弹出（(app)/layout 挂载）
- 三步：① 建项目（名称 + slug 自动建议 + 「AI 靠它匹配仓库」人话解释）② 创建 MCP 密钥引导（解释最小权限；可跳密钥页或跳过）③ 邀请成员（复制注册链接 + 进入看板）
- 落旗：完成/关闭均写 `vibehub_onboarded=1`，不重复弹；空态「创建项目」按钮经 `vibehub:open-onboarding` 事件唤起

## 7.13 AI 活动面板（R60 实现）

- 入口：顶栏 ✦ 按钮（系统级，任何页面可达）；右侧滑出 320px，只动 transform，10s 自刷新
- 内容：`GET /api/activity/recent`（全员可读，service 脱敏——仅 key_name/key_prefix/工具名/耗时/结果）
- 行：工具名（mono）+ 密钥名与掩码前缀 + 相对时间 + 失败徽章；空态引导创建密钥
- Esc / 遮罩关闭

## 7.14 上传进度与失败重试（R61 实现）

- 传输：`api.uploadFile` 单文件 XHR（onprogress 百分比 + 60s 超时兜底）
- 队列：hooks/use-file-upload 逐文件并行；三态 uploading/done/error；done 1.5s 自动消失
- 展示：UploadProgressStrip——金色 2px 进度（scaleX 只动 transform）；失败红框 + 单文件「重试」
- 适用面：文件页三入口 + CreateBugDialog 粘贴区（看板 C 流程）

## 7.15 角色化导航与移动端入口（R59/R62 实现）

- 导航分组：primary 五项平铺；more（密钥/成员/设置）收进「更多」折叠（150ms 箭头旋转、展开态持久化、次要路由自动展开）
- 锁定态：非管理员见管理项为 Lock 图标 + 点击 toast「需要管理员权限」——隐藏改锁定，保可发现性
- 简洁模式：设置页开关（`vibehub_nav_simple`），隐藏「更多」入口，lib/nav-prefs 事件跨组件同步
- 移动端（<900px）：看板顶栏常驻「＋录缺陷」按钮（触屏无 C 快捷键）；对话框 `w-[calc(100vw-2rem)] max-h-[85vh]` 适配；粘贴区按 `pointer: coarse` 切换「选择截图/文件」大按钮
