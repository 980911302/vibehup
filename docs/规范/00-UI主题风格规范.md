# VibeHub UI 主题风格规范（2026）

> 本规范是全部前端实现的**唯一审美与动效真理源**。基底：白泽观智（baize-guanzhi）设计语言；演化方向：2026 AI-native 工作台。
> 规则优先级：**动效必须有意义 > 性能（只动 transform/opacity）> 好看**。任何违反本规范的样式不允许合入。

### 1.4 动效系统（核心章节）

```css
--ease:cubic-bezier(.32,.72,0,1);        /* 主缓动（观智 .4,0,.2,1 的 2026 演化，更"果味"） */
--ease-out:cubic-bezier(.16,1,.3,1);     /* 入场专用 */
--ease-spring:cubic-bezier(.34,1.56,.64,1); /* 回弹（仅小元素：徽章/角标/新卡片滑入） */
--dur-fast:140ms;   /* hover/点击反馈（观智 120-180 中值） */
--dur-base:220ms;   /* 浮层进入/切换 */
--dur-exit:140ms;   /* 一切退出一律快于进入 */
--dur-slow:320ms;   /* 抽屉/侧栏折叠/页内大位移 */
```

**全局动效铁律**：
1. 只动画 `transform` 与 `opacity`（60fps 保证）；`width/height/top/left` 动画仅允许进度条与折叠容器，且必须附 `will-change`。
2. 退出比进入快（`--dur-exit < --dur-base`），符合「来有影去无踪」。
3. `prefers-reduced-motion: reduce` 时，全部动效降为 `opacity .12s`，禁用弹跳与流光。
4. 任何动效必须承担反馈职责；纯装饰动画只允许三处：登录页金色聚光、AI 流光、空状态浮动。

### 1.5 关键帧库（直接落 `globals.css`）

```css
@keyframes vh-panel-in  { from { opacity:0; transform:translateX(20px) } to { opacity:1; transform:none } }        /* 侧抽屉/右侧面板 0.28s ease-out */
@keyframes vh-pop-in    { from { opacity:0; transform:translateY(8px) scale(.96) } to { opacity:1; transform:none } } /* 下拉/气泡 0.18s ease，origin 随锚点 */
@keyframes vh-modal-in  { from { opacity:0; transform:scale(.96) } to { opacity:1; transform:none } }               /* 模态 0.22s ease */
@keyframes vh-card-in   { from { opacity:0; transform:translateY(6px) scale(.98) } to { opacity:1; transform:none } } /* 新卡片滑入 0.24s ease-spring */
@keyframes vh-collapse  { from { opacity:1; transform:scaleY(1) } to { opacity:0; transform:scaleY(.9) } }          /* 折叠区收起 0.14s，origin top */
@keyframes vh-toast-in  { from { opacity:0; transform:translateY(12px) } to { opacity:1; transform:none } }          /* Toast 0.22s ease-spring */
@keyframes vh-breathe   { 0%,100% { box-shadow:0 0 0 3px var(--gold-bg) } 50% { box-shadow:0 0 0 7px transparent } } /* 呼吸圆点 1.4s infinite（观智 recDotPulse） */
@keyframes vh-shimmer   { from { background-position:-200% 0 } to { background-position:200% 0 } }                  /* 骨架/金色流光 1.2s linear infinite */
@keyframes vh-float     { 0%,100% { transform:translateY(0) } 50% { transform:translateY(-4px) } }                  /* 空状态浮动 3s infinite */
@keyframes vh-shake     { 0%,100%{transform:none} 25%{transform:translateX(-3px)} 75%{transform:translateX(3px)} } /* 错误抖动 0.16s 一次 */
```

## 2. 组件动效规格（逐个到帧）

### 2.1 侧边栏折叠/展开（重点）

```
折叠：width 232px → 64px，--dur-slow(320ms) --ease
  - 只动 width（附 will-change:width）；内部文字标签 opacity 1→0（140ms）后 display:none
  - 图标 20px 不变；导航项 active 左侧 2px 金色指示条随折叠平移
  - 底部用户卡：头像保留，名字/角色淡出；hover 折叠态整条 tooltip 显示名称
  - <900px 自动折叠为 icon 模式；overlay 模式（抽屉式）用 vh-panel-in 从左滑入 + 遮罩 fade 140ms
展开：reverse；指示条先到位（文字后出现），避免文字溢出动画
```

### 2.2 抽屉/面板（缺陷详情、密钥向导）

- 进入：`vh-panel-in .28s var(--ease-out)`；遮罩 `opacity 0→1 .14s`（遮罩永远比内容快）。
- 关闭：内容 `opacity→0 .14s`（不位移，去无踪），遮罩同步 fade。
- 拖拽把手（详情面板顶条）：hover 显示 `grab` 光标，按下 `grabbing`。

### 2.3 下拉/气泡/菜单

- 进入 `vh-pop-in .18s`；`transform-origin` 跟随锚点（顶栏菜单 top-left、用户卡 top-left、行内菜单 top-right）。
- 菜单项 stagger：首项 0ms、间隔 12ms 淡入（≤5 项，超出不 stagger）。
- hover 项：`background .12s`（观智规格），不位移不缩放。

### 2.4 加载（四件套，按场景选用）

| 场景 | 组件 | 规格 |
| --- | --- | --- |
| 首屏/切项目 | 骨架屏 | 与真实内容同构（看板 3 列×3 卡），`vh-shimmer` 1.2s；≤300ms 的内容不显示骨架（防闪烁） |
| 按钮操作中 | 按钮内 spinner | 14px 圆环 0.8s linear infinite；按钮宽度锁定（文字透明化，防抖动） |
| AI 思考/MCP 调用 | 金色流光细条 | 顶部 2px，`--grad-ai` + `vh-shimmer`；配 `vh-breathe` 金点 |
| 长任务/上传 | 进度条 | `width .3s --ease`（观智存储条规格）；并发上传显示 `2/5` |

铁律：**任何加载态必须有文字或结构提示**，禁止只有一个转圈；超过 5s 的等待显示「仍在处理…」+ 取消入口。

### 2.5 关闭与撤销

- 模态右上关闭钮：32px 圆、0.5px 边、hover `bg .15s`（观智 rec-panel-close 规格），点击后内容 `fade .14s`。
- 删除/批量操作：**不弹确认框**，Toast `vh-toast-in .22s ease-spring` 带撤销按钮 + 5s 倒计时进度条（条本身 `width linear 5s`）；时间到 action 消失，Toast 再停留 1s 淡出。
- 仅「删项目/移除成员/转让 Owner」用 ConfirmDialog（输入名称确认，确认钮危险色）。

### 2.6 看板卡片与拖拽

- hover：`translateY(-1px) + shadow-1`，.14s。
- 拖起：`scale(1.02) + shadow-2`，跟手（无缓动延迟）；目标列：边框金色 18% + 底色 `--gold-bg` 过渡 .14s；非法放置：列头 `vh-shake .16s` 一次。
- 落位：新位置卡片 `vh-card-in .24s ease-spring`。
- AI 更新到达：卡片顶部 1px 金色流光扫过（`--grad-ai` + background-position .4s）。

### 2.7 主题切换

- 切换瞬间：全页 `opacity .12s` 交叉淡化（不做颜色过渡动画——大面积 color transition 掉帧）。
- 按钮：☾/☀ 图标旋转 180° + 淡入 .22s（观智 theme-icon 交换的演化）。
- 选择持久化 localStorage，`data-theme` 挂 `<html>`；**登录页恒定 Daylight**（产品的印刷品）。

### 2.8 内联编辑

- 点击文字 → 边框 `--brand` + 3px 18% 外溢光晕（focus 规格），Enter 保存（`vh-card-in` 微反馈），Esc 还原。
- 保存中：文字旁 12px spinner；失败：`vh-shake` + 红边 + 错误 tooltip。

### 2.9 命令面板与 Toast

- 命令面板：`vh-modal-in .22s`；遮罩 `blur(4px)`；结果项键盘高亮 = 左侧 2px 金线 + `--gold-bg` 底；输入防抖 150ms。
- Toast 堆叠：新Toast从底部 `vh-toast-in`，旧Toast上推移让位 .18s；最多 3 条，超出静默合并（同 key 更新）。

---

### 2.10 首启向导对话框（R56）

- 进入：Radix 缩放 + 淡入 220ms；退出快于进入（140ms）；遮罩 40% 黑 + 2px 模糊
- 步骤指示：三圆点（当前金色 `--gold-bg` 底 + `--gold` 字，其后 `--bg-elevated`），步骤间连线 1px `--border-subtle`
- 表单：输入框 9px 高、聚焦 `--brand` 边框（既有 input 规格）；主按钮金色描边款（`--gold-bg` 底 + `--gold` 字 + `--gold` 边）
- 「去创建密钥」跳转后向导关闭并落旗（localStorage），不回看

### 2.11 AI 活动滑出面板（R60）

- 位置：右侧固定 320px 宽，从右滑入 200ms（**只动 transform**：translateX(16px)→0 + 淡入同帧）
- 遮罩：40% 黑点击关闭；`z-index` 低于抽屉（40）、高于看板
- 列表项：卡片 `--bg-card` + 1px `--border-subtle`；工具名 mono；失败徽章 `--danger` 15% 底 + `--danger` 字
- 10s 静默自刷新——不得出现加载闪烁（首次外不显示 loading）
- 关闭：Esc / 遮罩 / ✕，退出动画省略（即时关闭，符合「退出快于进入」）

### 2.12 上传进度条（R61）

- 进度条：文件行底部 2px `--gold`，`scaleX` 200ms 线性（**只动 transform**）；完成即整行打勾 1.5s 后移除
- 失败：行整体 1px `--danger` 60% 边框 + `--danger` 8% 底，**无进入动画**（即时反馈）；「重试」按钮 hover `--gold-bg`
- 三态图标：上传中金点 / 完成 `--ok` 勾 / 失败 `--danger` 叹号

### 2.13 「更多」导航折叠与锁定态（R59）

- 折叠开关：箭头 150ms 旋转 180°（transform）；次级组展开时组内缩进 10px（布局变化允许，不做高度动画）
- 锁定态（非管理员）：整行 opacity .55，hover .8；Lock 图标替代功能图标，combo 位显示「需管理」
- 简洁模式：隐藏「更多」入口但不改变主五项动效

## 4. 图标与插画

- 图标库：Lucide，统一 `strokeWidth={1.8}`、`size` 16/20/22 三档，禁用填充图标。
- AI 标识：金色星尘（四角星 + 渐变），仅用于 AI 创建/写入的内容。
- 空状态插画：1.8 描边线性 + 单处金色渐变点缀 + 大量留白；`vh-float` 3s 微浮（唯一允许的装饰循环）。
- 头像：姓氏首字 + 8 色板（email hash 取色），Owner 1.5px 金环。

## 5. 无障碍与对比度

- 两套主题正文对比度 ≥ 4.5:1（`--text-secondary` on `--bg-card` 已验算）；金色只作点缀不作正文。
- 焦点可见：全交互元素 `:focus-visible` 2px `--brand` 外环 + 2px offset。
- 动效降级：`prefers-reduced-motion` 全局生效（见铁律 3）。
- 触达：键盘可完成核心链路（登录→建单→改状态）；焦点顺序遵循 DOM 序。

## 6. 性能预算

- 单页首屏 JS ≤ 200KB（gzip）；CSS ≤ 40KB。
- 动画只用 transform/opacity；折叠容器动画附 will-change 且动画结束移除。
- 主题切换禁止大面积 color transition。
- 图片：缩略图走服务端降采样产物，列表页 lazy + 4:3 固定占位（防 CLS）。
